# Portfolio Website — Sabbir Uddin Akash

A responsive, personal portfolio website designed to showcase projects, professional experience, certifications, and skills in **Data Analytics** and **Data Science**. Built using modern web technologies, HTML5, CSS3, and JavaScript libraries.

---

## 📌 Project Overview

This repository contains the front-end source code for the personal portfolio website of **Sabbir Uddin Akash**. The layout is designed to present technical expertise, key metrics, dynamic charts, and project repositories in an organized, interactive format.

---

## ✨ Features & Sections

* **Introduction:** Dynamic typing text effect (`typing.js`) highlighting primary roles and skills.
* **About Me:** Profile summary, quick stats, core competencies, and progress bars for analytical skills.
* **Professional Experience:** Detailed career history highlighting data accuracy, reporting, and operational background.
* **Certifications & Education:** Highlighted course completion links and academic credentials.
* **Project Showcase:** Interactive project cards linking directly to Power BI reports, SQL files, dynamic Excel workbooks, and GitHub repositories.
* **Counter & Stats:** Visual representation of key metrics (30+ completed projects, achievements, etc.).
* **Contact Details & Social Links:** Direct connections to LinkedIn, GitHub, Email, and downloadable Resume/CV.

---

## 🛠️ Tech Stack & Dependencies

* **Frontend:** HTML5, CSS3, JavaScript (ES6)
* **Framework:** Bootstrap
* **Libraries & Plugins:**
  * jQuery
  * Owl Carousel
  * AOS (Animate On Scroll)
  * Magnific Popup
  * IonIcons & IcoMoon Icons
  * Google Fonts (Poppins)
